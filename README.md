# Gooday

enquanto eu fazia eu tentei colocar um vídeo com a logo animada na tela inicial, mas não consegui fazer funcionar do jeito que eu queria, mesmo assim, continuei pesquisando outras formas de melhorar o projeto e fui adicionando algumas coisas além do que eu tinha feito inicialmente

Uma delas foi o **Modal** pq eu estava usando `alert()` para mostrar mensagens de cadastro realizado, login correto ou algum erro, como eu achei o alert muito simples e não combinava tanto com a aparência do aplicativo, pesquisei uma alternativa e troquei pelos modais, ai consegui deixar as mensagens mais parecidas com um popup do próprio aplicativo

Também coloquei uma validação no cadastro, a pessoa precisa digitar a senha e depois repetir a mesma senha no campo de confirmação, se as duas senhas não sejam iguais, o cadastro não é realizado e aparece uma mensagem informando que as senhas não coincidem, se estiver tudo certo, o cadastro é feito normalmente

Na tela de acesso também coloquei uma lógica para verificar o e-mail e a senha cadastrados, Se os dados estiverem corretos, o usuário consegue continuar para a próxima página, se o e-mail ou a senha estiverem errados, o acesso é negado e aparece um modal avisando que os dados estão incorretos

Outra coisa que eu adicionei foi o **olhinho no campo de senha** se vc clicar no ícone é possível visualizar o que foi digitado, clicando novamente, a senha volta a ficar escondida

No final, além das 4 telas, tentei colocar alguns detalhes que deixassem o projeto mais completo
